# 个人资料分享卡端到端验收

仅连接本机 Docker 服务（前端 5173、后端 8000），创建临时账号并在结束时删除。不会访问外部业务服务。浏览器使用 Playwright；脚本不属于默认协议冒烟命令。

准备已安装的 `playwright` 模块和浏览器，`backend/.env` 提供本机门禁配置。模块不在项目依赖路径时，将 `PLAYWRIGHT_MODULE` 设为该模块绝对路径；使用系统浏览器时，将 `E2E_BROWSER_PATH` 设为可执行文件路径。

在仓库根目录执行：

```powershell
node --env-file-if-exists=backend/.env tests/profile-share-e2e.cjs
```

脚本通过真实登录与“我的”页面编辑资料，验证：

- `/profile` 不再提供编辑按钮；保存后的昵称、头像和简介用于分享卡片。
- 生成按钮随机选择六款底图，允许重复。最多进行 120 次真实生成，收集六款结果；不替换内部随机逻辑。
- 下载为 1536×1024 PNG，文件字节与预览完全一致。
- 375px 屏幕下卡片不越界；长昵称、长用户名、200 字简介及内部换行能够生成。
- 图片网络失败时显示原因、禁用下载并移除旧预览；恢复网络后可重试。

输出 PNG 和页面截图写入 Git 忽略的 `.tmp/`。需查看六款卡片、长资料和换行资料图片，检查文字边界及人物遮挡；生成成功本身不能代替视觉检查。脚本若被强制终止，可能来不及清理临时 `card_` 账号。
